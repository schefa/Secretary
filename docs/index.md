# Secretary Documentation

Secretary is a Joomla 6 component for running a small business's back office: invoicing, contacts, products, time and project tracking, and reporting. This documentation covers how the component is organized and how to use each section, from the admin backend at `/administrator/index.php?option=com_secretary`.

For installing the extension, local development, packaging, and linting, see the [project README](../README.md).

## Contents

- [Concepts](concepts.md) - the core ideas (Business, Folders, record types) that everything else builds on
- [Dashboard](dashboard.md) - the landing page after login
- [Documents](documents.md) - invoicing and accounting, the most-used part of the component
- [Contacts](contacts.md) - customers, employees, and suppliers
- [Products](products.md) - inventory/catalog items
- [Time Management](time-management.md) - events, projects, and locations
- [Reports](reports.md) - revenue and activity reporting
- [Categories (Folders)](categories.md) - the folder trees behind Documents, Contacts, Products, and more
- [Settings](settings.md) - component-wide configuration and access control
- [PDF generation](pdf.md) - installing mPDF or Dompdf so Preview, Email, and PDF export work
